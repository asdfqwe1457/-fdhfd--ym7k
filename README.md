DIY装修——拖拽式外卖小程序首页可视化搭建
对外卖平台而言首页是用户第一印象。布局清晰视觉美观的首页能显著提升留存和转化。海狐外卖系统提供强大页面装修功能，支持平台运营者自定义编辑小程序首页，无需编写代码即可实现个性化布局。

装修系统核心是组件库。系统提供轮播图、商品列表（多种样式）、优惠券入口、公告栏、图文导航、搜索栏等功能组件。搭建时从左侧点击添加组件，在右侧配置内容，在中间拖拽调整位置或删除。三勾点餐系统提供海报轮播、商品档案（不同样式商品展示区）、优惠券、公告栏、图文导航等多种模板样式。

拖拽式可视化编辑器操作类似制作PPT。用户可自由调整页面布局：替换门店LOGO、更换主题色、调整轮播广告图、修改底部导航栏。前端拖拽引擎基于Vue拖拽组件（如vuedraggable）实现，将组件库组件拖入预览区域，通过JSON配置描述页面结构。后端保存JSON配置，小程序端动态渲染。

系统支持创建多个页面并切换使用，同一时间只有一个页面作为默认首页。可根据节日活动创建不同主题首页按需切换。新建代理区域默认没有页面装修配置，需手动创建后在小程序用户端显示。编辑完成后点击“开启默认模板”开关，该页面即作为当前代理区域默认首页。

建议首屏聚焦：将最重要功能（外卖入口、优惠券领取）放在首屏，确保用户无需滑动即可看到；Banner轮播图控制在3-5张；功能入口图标简洁明了配简短文字。DIY装修将页面搭建从开发者代码工作转变为运营者拖拽操作，大幅降低运营门槛和迭代成本。
